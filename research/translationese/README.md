# 翻訳調および文体の癖に関する候補規則の計測

本文書は、追加候補とした `coji/natural-japanese`（MIT License、Copyright (c) 2026 coji）の各規則について、本リポジトリの評価基準に沿って計測を実施した記録である。

規則の採択には、実測値における人間と AI の範囲が重ならないこと、または明文化されたスタイルガイドの規約を出典とともに提示できることのいずれかを満たす必要がある。候補の提案は人が行ってよいが、採否は計測値に基づいて決定する。

```sh
python measure_patterns.py corpus/cache/k8s   # 翻訳調のパターンと語の候補
python measure_flow.py                        # 段落頭の接続詞と文末の同形反復
```

`corpus/cache/k8s/` には、同一文書に対する人間訳と AI 訳のペアが格納されている。同一原文に基づく訳文同士を比較対象とするため、分野や題材の違いが比較結果の差に影響しない。

本計測によって採択された規則はない。不採択の理由は `corpus/baselines.toml` の `[rejected]` に記載されており、経緯は決定記録の D-34 にまとめられている。
