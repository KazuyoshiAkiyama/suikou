# 翻訳調・手癖の候補規則の計測

この文書は、`coji/natural-japanese`（MIT License、Copyright (c) 2026 coji）が定める規則を候補に取り、
このリポジトリの基準に照らして計測した記録である。

規則として追加できるのは、実測値で人間の範囲と AI の範囲が重ならない場合か、
明文化されたスタイルガイドの規約を出典付きで示せる場合に限る。
候補を挙げるのは人でかまわないが、採用するかどうかは計測値で決める。

```sh
python measure_patterns.py corpus/cache/k8s   # 翻訳調のパターンと語の候補
python measure_flow.py                        # 段落頭の接続詞と文末の同形反復
```

`corpus/cache/k8s/` には、同じ文書を人間が訳したものと AI が訳したものが組になって入っている。
同一の原文の訳どうしを比べるので、分野や題材の違いが差として混ざることはない。

計測の結果、採用に至った規則は一つもなかった。
不採用の理由は `corpus/baselines.toml` の `[rejected]` に、経緯は決定の記録の D-34 に書いてある。
