# research

research は、指標の探索や較正を行う Python スクリプト群であり、本番の実行経路には含まれない。

ここに配置されたスクリプトは全指標の参照実装として機能する。Rust 側の実装が同一の値を返すことは、ゴールデンテストによって検証する。

## インストール

```sh
pip install fugashi unidic-lite spacy --break-system-packages
python -m spacy download en_core_web_sm
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `jametrics.py` | 日本語文書の指標算出 |
| `enmetrics.py` | 英語文書の指標算出 |
| `mcheck.py` | M1〜M7 の規則判定 |

## 実行方法

```sh
python jametrics.py 'corpus/**/*.md'
python enmetrics.py 'corpus/**/*.md'
python mcheck.py   'corpus/**/*.md'
```

各スクリプトは結果を JSON 形式で標準出力へ書き出す。得られた出力をそのまま `tests/golden/expected/` 配下に保存し、テストの期待値として利用する。

## 本番実装から分離している理由

深い構文解析を要する指標ほど、実験設計の違いによる影響を受けやすい。分詞節、名詞化、多重修飾、係り受け距離はいずれもここで検証したが、人間の文章が示す範囲と重なったため不採用とした。

検証を経て有効性が確認された指標だけを Rust 実装へ移植する。未検証の指標を本番へ組み込まないようにするためである。

実行性能の面でも制約がある。spaCy のロードには2秒から5秒を要するため、hooks から繰り返し呼び出す運用では毎回その分の待ち時間が発生する。したがって、Python 側の処理を本番の実行経路に組み込むことはできない。

## 変更時の注意点

このディレクトリで生成する期待値は、Rust 実装の振る舞いを規定する基準となる。スクリプトに変更を加えた際は期待値も再生成し、Python 実装と Rust 実装の双方が同一の値を返すことを確認する必要がある。
