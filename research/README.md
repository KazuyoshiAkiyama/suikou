# research

探索と較正のための Python である。本番の経路には入らないものである。

ここにある書いたものが、すべての指標の参照になる。
Rust のの実装がこれと同じ値を返すことを、ゴールデンテストで確かめることになる。

## 入れ方

```sh
pip install fugashi unidic-lite spacy --break-system-packages
python -m spacy download en_core_web_sm
```

## 中身

| ファイル | 中身 |
|---|---|
| `jametrics.py` | 日本語の文書指標 |
| `enmetrics.py` | 英語の文書指標 |
| `mcheck.py` | M1 から M7 の規則 |

## 使い方

```sh
python jametrics.py 'corpus/**/*.md'
python enmetrics.py 'corpus/**/*.md'
python mcheck.py   'corpus/**/*.md'
```

いずれも JSON を標準の出口に出す。
その出力をそのまま `tests/golden/expected/` に置いて、期待の値として使う。

## この層を分けている理由

深い構文の解析が要る指標ほど、実験の組み立てに敏感である。
分詞節と名詞化と修飾の積み重ね、そして係り受けの距離はここで試したものである。
そのいずれも人間の幅と重なったため、落とすことになった。

ここで使えると分かった指標だけを、Rust のの実装に移す。
そのようにするのは、確かめを通っていないものを本番に置かないためである。

spaCy の読み込みには2秒から5秒かかる。
hooks から何度も動かす使われ方では、その時間がそのまま待ち時間になる。
そのため、この層を本番の経路に置くことはできない。

## 気をつけること

ここで作った期待の値は、Rust の側を縛るものになる。
そのため、ここを書き換えたときは期待の値も作り直すことになる。
作り直したあとは、両方のの実装が同じ値を返すかどうかを確かめる。
