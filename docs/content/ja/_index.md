suikou は技術文書向けの lint とハーネスであり、日本語と英語の文書を対象にする。

生成AIに書かせた技術文書には、語彙の選択以外にも目立つ傾向が出る。
具体的には、比喩が多いこと、文末の形が偏ること、前後の文の接続が不自然になること、
細部まで書き込みすぎて保守しづらい構成になることである。
suikou はこれらの傾向を文書の中から検出する。
さらに、検出した箇所を手掛かりにして、文書を保守しやすい形へ直していく。

suikou の規則は、どれも実測値か、文書化された規約に基づいて定めている。
感覚だけで決めた規則は含めていない。
文体の特徴について感覚で立てた仮説は、検証するとほとんどが当てはまらないからである。
この傾向は、互いに異なる分野の研究で共通して確かめられている。
各規則の根拠は、それらの研究と、コーパスを測定して得た値である。

この文書も、suikou が定める規則に沿って書いている。

## 導入と基本の操作

GitHub Releases で配布している書庫を展開し、`suikou` を PATH の通ったディレクトリに置けば導入は終わる。
日常の作業は、次のコマンドでまかなえる。

```sh
suikou plot docs/design.md --doctype design  # 書く前に構成を決める
suikou brief --doctype design                # 生成の前にプロンプトへ貼る
suikou check docs/design.md                  # 書いたものを検査する
```

文書を書くときに守る規範と手順は、[書き方](writing/)で説明している。
自分の文書に合わせて調整する手順は、[調整](tuning/)にまとめてある。
導入方法と各コマンドの説明は[設計](design/)にある。
指標の厳密な定義は[指標](metrics/)に、それぞれを決めた経緯は[決定の記録](decisions/)に記録している。
