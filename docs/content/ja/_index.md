suikou は、日本語と英語の技術文書を対象とする lint およびハーネスである。

生成AIが出力した技術文書には、語彙の選択以外にも固有の傾向が現れる。具体的には、比喩の過剰な使用、文末形式の偏り、文間の接続の不自然さ、細部を過剰に記述してメンテナンス性を損なう構造が挙げられる。suikou の役割は、こうした特徴を検出し、その結果をもとに文書をメンテナンスしやすい構成へと改善していくことにある。

suikou で採用している規則はすべて、実測値または明文化された規約に基づいており、直感で定められた規則は含まれない。文体の特徴に関する直感的な仮説は、検証すると大半が成り立たないことが異なる研究領域でも同様に確認されているためである。その根拠は、研究成果とコーパスの測定値にある。

本ドキュメント自体も、ここで定義する規則に従って執筆されている。

## 使い方

インストールするには、GitHub Releases のアーカイブを展開し、`suikou` を PATH の通ったディレクトリに配置する。日常的な作業では、以下のコマンドを使用する。

```sh
suikou plot docs/design.md --doctype design  # 書く前に構成を決める
suikou brief --doctype design                # 生成の前にプロンプトへ貼る
suikou check docs/design.md                  # 書いたものを検査する
```

執筆時の規範と手順は[書き方](writing/)にまとめられている。自身の文書に合わせた調整手順は[調整](tuning/)を参照する。インストール手順と個別の詳細な説明は[設計](design/)に記載されている。指標の厳密な定義は[指標](metrics/)、決定の経緯は[決定の記録](decisions/)で確認できる。
