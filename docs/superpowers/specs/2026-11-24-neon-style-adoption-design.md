# neon の文体をこのリポジトリの基準として採用する

## 意図

2026-11-24 のコミット 7d07fc5 で Gemini（neon）が26ファイルを書き直した。その文体をこのリポジトリの文書の基準として採用し、現行の日本語ルールが出す警告を解消する。

## 目標

- このリポジトリの日本語文書に対して、error と warning をゼロ件にする。
- 偽陽性を是正し、ルールの精度そのものを上げる。
- 緩和の経緯と、その適用範囲を記録に残す。

## 非目標

- `crates/suikou-core/profiles/oss.toml` を変更しない。
- 利用者の文書に対する判定を変えない。
- 英語側のルールを変更しない。書き直しによって局所指摘が25件から1件へ減っており、調整の必要がない。

## アンチゴール

AI らしさを検出する指標を、検出力を失うまで緩めること。既定の閾値は人間コーパスの実測に基づく較正であり、この採用はそれを置き換えるものではない。

## 制約

- CLAUDE.md は、閾値の緩和をユーザーとの合意として記録し、独断で行わないことを求めている。
- `baseline.rs` は4件未満の標本では較正を拒否する。手で置く閾値もこの水準を下回ってはならない。
- `corpus/baselines.toml` の `[rejected]` に `ja.gairaigo_ratio` が「人間と重なる」として記録済みであり、外来語率を指標として追加できない。

## 実測値

書き直し前後の中央値を、人間コーパスと AI コーパスの実測範囲と並べる。

| 指標 | 人間ネイティブ | AI 4モデル | 書き直し前 | neon |
|---|---|---|---|---|
| renyo_te_ratio | 1.79–2.00 | 3.62–15.94 | 1.42 | 9.00 |
| renyo_per_1k | 2.29–2.71 | 4.81–6.75 | 2.48 | 4.60 |
| kango_ratio | 0.326–0.397 | 0.455–0.519 | 0.456 | 0.550 |
| mattr100 | 0.569–0.581 | 0.629–0.665 | 0.585 | 0.611 |
| demonstrative_per_1k | 5.69–6.47 | 1.38–3.39 | 8.14 | 5.72 |

`renyo_te_ratio` は AI 範囲の中央に入り、`kango_ratio` は AI 範囲を超える。`demonstrative_per_1k` は人間ネイティブの範囲に改善した。

## アプローチ

検討した3案のうち、採用するのは案2である。

**案1 既定の閾値を neon の実測値から引き直す。** `oss.toml` を書き換える。採らない。AI 4モデルの実測範囲が丸ごと閾値の下に収まり、`renyo_te_ratio` と `kango_ratio` が検出力を失う。ツールの主張そのものが変わる。

**案2 このリポジトリの文書に限って緩和する。** `.suikou/profile.toml` の `[thresholds]` に、`suikou baseline` で較正した値を置く。標本はこのリポジトリの日本語文書9件で、4件以上という条件を満たす。既定の閾値は利用者向けの較正として保たれる。

**案3 文体を採用したうえで、連用中止と漢語を neon の文章の中で下げる。** 緩和を伴わない。採らない。ユーザーが緩和を選択した。ただし案2と排他ではなく、後から適用できる。

型ごとの `[doctype.*]` に手で値を置く方法も検討したが、採らない。log、design、howto、overview、readme の標本がいずれも1件であり、`baseline.rs` が拒否する水準を手で迂回することになる。D-41 が doctype 調整を導入した根拠は README 240件と参照コーパス652件の実測であって、1件ではない。

## 決定した内容

### 閾値の緩和

`.suikou/profile.toml` を新規に作成し、`[thresholds]` へ較正値を書く。較正は次のコマンドで再現する。

```sh
suikou baseline CLAUDE.md README.ja.md docs/content/ja/*.md --lang ja
```

| 指標 | 既定 | 較正値 |
|---|---|---|
| ja.renyo_te_ratio | 3.0 | 23.21 |
| ja.renyo_per_1k | 4.0 | 9.36 |
| ja.mattr100 | 0.60 | 0.640 |
| ja.kango_ratio | 0.52 | 0.590 |
| ja.list_ratio | 0.25 | 0.283 |
| ja.prose_ratio | 0.75 | 0.767 |

`reason` に、この緩和がこのリポジトリの文書に限るものであり、`oss.toml` の既定を置き換えないことを明記する。

### 指示詞の扱い

`ja.demonstrative_per_1k` は較正できない。`baseline` が「較正した境界 -1.76 が値域の外に出て、この閾値は永久に発火しない」として拒否する。この指標は緩和の対象とせず、既定の 4.5 を保つ。下回っている3件に指示詞を補う。

| 文書 | 実測値 |
|---|---|
| docs/content/ja/design.md | 3.317 |
| docs/content/ja/tuning.md | 3.433 |
| docs/content/ja/_index.md | 3.565 |

neon の書き直しはこの指標を中央 5.72 へ改善しており、人間ネイティブの範囲 5.69–6.47 に入っている。文書を直す方向が文体に反しない。

### 偽陽性の是正

`.suikou/register-allow.toml` へ追記する。

カタカナ対応表から除外する語。

| 語 | 理由 |
|---|---|
| 検査 | lint の検査を指す。`テスト` は `cargo test` を指し、置換すると誤りになる（27件） |
| 事例 | 技術文書で定着している |
| 保守 | メンテナンスと併用する |
| 書式 | 出力の書式を指す |
| 層 | レイヤーと併用する |
| 走査 | 文字列の走査を指す |

和語の指摘から除外する語。

| 語 | 用例 |
|---|---|
| 定める | 規約が定める（9件） |
| 満つ | 4件に満たない |
| 偏り | 分布の偏り。`偏る` は登録済みだが名詞形が漏れている |
| 食い違う | 期待値と定義が食い違う |
| 絞り込む | 条件で候補を絞り込む |
| 上がる | 測定値が上がる |
| 改める | 名前を改める |
| 揃う、揃える | 標本が揃う |

`register.rs` にガードを足す。`register/rare-wago` が `トレイト` を `糸` と解析して3件検出する。表層がカタカナのみの語を和語の判定から除外する。未知語に対する形態素解析の破綻であり、allow リストでは直らない。

### 記録

`docs/content/ja/decisions.md` と `docs/content/en/decisions.md` に D-51 を追記する。採用した文体、緩和した閾値、その適用範囲、および案1を採らなかった理由を書く。

## 残る案件

段落単位の `kango_ratio` を局所指摘として追加する案は、別の案件として切り分ける。実測では閾値 0.64 で書き直し前の 3.6% に対し neon が 15.5% であり、4.3倍に分かれる。指す先は D-27 の「漢語の名詞を重ねない」そのものである。指標の追加には計測の配線、位置の報告、単体テスト、ゴールデンテストが必要で、この採用とは規模が異なる。

段落単位の計測は指標ごとに成否が分かれる。`renyo_te_ratio` は `MIN_TE_FOR_RATIO` の門により562段落のうち38段落しか値が出ず、成立しない。`renyo_per_1k` は測れるが、超過が段落の半数に散っており位置を指せない。

## 実装者に委ねる事項

- `.suikou/profile.toml` と `.suikou/register-allow.toml` の記述順序および註釈の文面。
- `register.rs` のカタカナ判定を置く位置。既存の `is_target` に足すか、別の関数に分けるか。
- 指示詞を補う具体的な文。各文書の主題に沿わせる。
