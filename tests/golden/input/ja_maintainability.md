# 設定の反映

設定ファイルを書き換えたあと、変更を反映させる手順は以下のとおり。

- 設定ファイルの構文を検証する。
- サービスを再読み込みする
- ログを確認して、エラーが出ていないことを見る。

この手順には注意点がある。再読み込みは設定の一部しか反映しない。
現在の実装では、ポート番号の変更は再起動しないと反映されない。
最新の版では挙動が変わる可能性がある。

## 3つの失敗パターン

よくある失敗は3つある。一つは構文検証を飛ばすこと、二つは再起動と再読み込みを取り違えること、
三つは古い設定がキャッシュに残っていることである。

対象となるファイルは:

1. `/etc/app/main.conf`
2. `/etc/app/conf.d/*.conf`

## 2. 検証の方法

検証には専用のコマンドを使う。構文エラーがあれば行番号とともに表示される。
エラーの種類は、括弧の不一致、未知のキー、型の不一致などである。
