# キャッシュの無効化

キャッシュは、一度計算した結果を保存しておき、次に同じ入力が来たときに再利用する仕組みである。
計算が重いほど効果が大きい。一方で、元のデータが変わったときに古い結果を返してしまう危険がある。
この危険を避ける操作を無効化と呼ぶ。

無効化の方法は大きく分けて二つある。時間で切る方法と、変更を検知して切る方法である。
時間で切る方法は実装が簡単だが、有効期限の長さをどう決めるかが難しい。
短くすればキャッシュの効果が下がり、長くすれば古い結果を返す時間が伸びる。

変更を検知して切る方法は正確だが、変更の通知を受け取る経路を用意しなければならない。
データベースのトリガーを使ったり、更新処理の中で明示的に無効化を呼んだりする。
経路が一つでも漏れると、そこから古い結果が漏れ出す。

実務では両方を組み合わせることが多い。変更の検知を主として、
取りこぼしに備えて長めの有効期限を保険として置く。
